# Ace Plugins

| Plugin | What it is |
|---|---|
| [**WRAITHCORE**](WraithCore/) | **Flagship: sonar synth + 808 QUAKE + Snap-Heap-style 26-module FX rack, mod matrix, 108-preset browser** |
| [SonarWraith](SonarWraith/) | Glitch / atmos / sonar-blip synth |
| [DepthCharge](DepthCharge/) | Everything SonarWraith does + an 808 engine (punch, slides, dirt, wobble, growl) |

Every push builds all three plugins for Windows (see the **Actions** tab).
Download `WraithCore-Windows` (or `SonarWraith-Windows` / `DepthCharge-Windows`) from a finished run and copy the
`.vst3` folder into `C:\Program Files\Common Files\VST3`.
